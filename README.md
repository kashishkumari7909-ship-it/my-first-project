# Portfolio Website

A clean, modern, and responsive personal portfolio template built with HTML5 and CSS3.

## Features
- **Responsive Layout**: Designed to look great on desktop, tablet, and mobile devices.
- **Modern UI**: Clean typography, subtle micro-interactions, and a cohesive color palette.
- **Sections**:
  - Hero with call-to-actions
  - About me section with statistics
  - Featured Projects grid
  - Core Skills categorized by domain
  - Contact Form
- **Zero Dependencies**: Pure HTML and CSS without external JavaScript framework bloat.

## Getting Started
Simply open `index.html` in your web browser.

## Customization
- Edit `index.html` to update your personal details, project descriptions, and links.
- Modify CSS variables in `style.css` (`:root`) to quickly customize color themes.
